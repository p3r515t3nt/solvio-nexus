# Speaker Identity – Entwurfsrahmen

Der derzeitige ausdrückliche Erinnerungsweg am Raummikrofon kann auch durch
Gäste ausgelöst werden. Eine automatische oder biometrische Identifizierung
des Besitzers wird hier nicht als umgesetzt behauptet.

Eine spätere Lösung muss die Herkunft einer Äußerung, die erkannte Person,
die Unsicherheit der Erkennung und die erlaubte Gedächtnisaktion getrennt
behandeln. Eine Raumzuordnung, Netzwerkverbindung oder Formulierung wie
„merk dir“ reicht allein nicht als Nachweis der Sprecheridentität.
Unklare Zuordnungen dürfen keine verlässliche Besitzeridentität vortäuschen.

Der Entwurf ändert keine Core-Berechtigung und keine iPhone-Freigabe.
Gesonderte Tests müssen neben bekannten Sprechern auch Gäste, Fehlzuordnung,
fehlende Identität und Gerätewechsel abdecken. Echte Aufnahmen und persönliche
Stimmprofile gehören nicht in öffentliche Fixtures oder Fehlerberichte.
